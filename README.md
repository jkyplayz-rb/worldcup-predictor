# worldcup-predictor

Full-stack FIFA World Cup prediction platform built with Flask and SQLite.

## Features

- User authentication
- Match predictions
- Leaderboard system
- FIFA rankings page
- Group stage filtering
- World Cup fun facts
- Responsive dark UI

## Tech Stack

- Python
- Flask
- SQLAlchemy
- SQLite
- HTML/CSS
- JavaScript

## Run Locally

```bash
git clone https://github.com/jkyplayz-rb/worldcup-predictor.git
cd worldcup-predictor
pip install -r requirements.txt
python3 app.py
```
